# INVALL

Mi primer repositorio en GitHub.

## Objetivo
Aprender a organizar y desarrollar proyectos con GitHub y ChatGPT, paso a paso.

## Estructura
- `docs/`: documentación.
- `src/`: código de futuros proyectos.
- `.gitignore`: exclusiones de archivos locales y secretos.

## Próximos pasos
1. Definir qué aplicación queremos crear.
2. Añadir el código a `src/`.
3. Documentar las decisiones en `docs/`.

No publiques contraseñas, tokens ni claves privadas.

> Esta es una plantilla inicial: aún no existe una aplicación ni un sistema de autenticación.
