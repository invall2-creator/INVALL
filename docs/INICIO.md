# Guía de inicio

Este repositorio permite empezar a trabajar con GitHub y ChatGPT.

## Conceptos
- **Repositorio**: proyecto con archivos y su historial.
- **Commit**: registro de cambios.
- **Rama**: línea independiente de trabajo.
- **Pull request**: propuesta para revisar e incorporar cambios.

Elegir qué proyecto crear en `src/`. No se incluye aún código de aplicación.
